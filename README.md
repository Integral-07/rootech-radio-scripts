# Rootech Radio - Scripts Archive

「Rootech Radio(ルーテックラジオ)」で配信した各回の原稿(台本)を保存するリポジトリです。

Rootech Radioは、技術ニュースを毎日自動生成してYouTubeに配信するAIラジオ番組です。
パーソナリティは「須藤」("sudo" にかけた名前)、一人語りでお届けしています。

## フォルダ構成

```
YYYY-MM/
  DD_トピック名.txt
```

例:

```
2026-08/
  27_バックエンド・DB.txt
  28_クラウド・インフラ.txt
2026-09/
  01_AI・機械学習.txt
```

各ファイルには、その回でそのまま読み上げられた原稿全文が入っています。

## 配信トピック(曜日ごと)

| 曜日 | トピック |
|---|---|
| 月 | AI・機械学習 |
| 火 | Web開発・フロントエンド |
| 水 | セキュリティ |
| 木 | バックエンド・DB |
| 金 | クラウド・インフラ |
| 土 | プログラミング言語・OSSトレンド / ハードウェア・ガジェット(2本) |
| 日 | 気になる企業ウォッチ / 週間まとめ(2本) |

## 備考

このリポジトリはバックエンドパイプラインから自動的にコミットされます。
原稿の生成には Gemini API を利用しており、各記事の情報が薄い場合は Google 検索で
補足しながら執筆しています。手動での編集は想定していません。
